# MarketPredict — Saudi V5 Web Application

MarketPredict is a FastAPI web application that predicts the pre-launch success probability of marketing campaigns using the frozen Saudi-calibrated V5 model suite.

## Quick demo

- Email: `demo@marketpredict.app`
- Password: `Demo12345!`
- The login page includes a one-click demo button.

## Vercel note

On Vercel, SQLite is stored under `/tmp` for demo-only persistence and may reset between serverless cold starts. For permanent multi-user prediction history, connect a persistent database such as Postgres.
